# HANOFFICE | 한오피스

전국 비상주사무실 주소 검색·입지정보·비대면 임대차계약·결제·계약관리 플랫폼.

## 제품 목표
- 다지점 비상주사무실 탐색과 비교, 지역별 가격·기간 견적
- 도로명주소·지번·우편번호·영문주소·지도·로드뷰·주변 관공서 등의 근거 기반 위치안내
- 고객 인증, 개인/법인 계약자 구분, 임대 적합성 검토
- 계약서 생성·전자서명·계약문서 보관 및 다운로드
- PG 연동(승인/취소/환불/웹훅 검증), 계약 만료·갱신 관리
- 우편물 접수·알림 및 지점별 운영관리

## 1차 데모
`index.html`은 별도 서버 없이 브라우저에서 여는 정적 프런트엔드 시제품입니다. 표시된 주소·가격·상품은 예시 데이터이고, 실제 계약 체결·결제·주소 사용 승인이 발생하지 않습니다.

## 출시 전 필수 게이트
1. 실제 임대 장소 및 소유/임차·전대 권한 확인
2. 사업자등록/법인등기 적합성의 업종·관할별 검토
3. 본인확인·개인정보 처리방침·보관/삭제 정책
4. 전자서명 및 계약서 무결성·전달 검증
5. PG 테스트 상점 승인·서버 측 결제금액 검증·웹훅 서명 검증·중복 요청 방지
6. 주문·계약·결제·환불 데이터 일관성, 접근 통제와 감사 로그
7. 모바일 접근성, 보안, 실제 사용자 시나리오 점검
